# 测试报告解析规则

## 1. 文件格式

### 文件命名
```
2026-05-12_vcp1.txt
2026-05-13_vcp1_vcp2_plb.txt
```

### 日期提取
- 从**文件名**提取：`2026-05-12` → `2026.05.12`
- 正则：`(\d{4})-(\d{2})-(\d{2})`
- 也支持旧格式 `05.12` → `2026.05.12`

### 线体提取
- 从**文件名**提取：包含 vcp1/vcp2/plb（不区分大小写）
- 多线体用下划线分隔
- 存储时转换为逗号分隔：`VCP1, VCP2, PLB`

---

## 2. 结构识别（【】标记）

报告使用【】标记不同区块：

| 区块 | 提取内容 |
|------|----------|
| 【今日{05/15}计划】 | 今日计划（标题用，不单独提取） |
| 【汇总如下】 | 分隔符 |
| 【生产线可测试时间总计：X小时】 | 可测试时间（小时） |
| 明细时间段： | 明细时间段（字符串） |
| 【测试场景】 | 测试场景描述 |
| 【现场正式工单LOT号】 | LOT号信息 |
| 【明细流程】 | 明细流程步骤 |
| 【问题汇总】 | 问题列表 |
| 【测试结果】 | 测试结果 |
| 【今日计划实际是否完成】 | 计划完成情况 |
| 【明日的测试计划】/【下周的测试计划】 | 下一步计划 |
| 需要协调事项： | 需要协调事项 |

---

## 3. 问题解析规则

### 3.1 问题来源
问题来源（来源）指问题的责任方/发起方：

| 来源 | 说明 |
|------|------|
| 投收板机 | 投收板机设备问题 |
| 自动化物流（海康） | 海康自动化物流问题 |
| 主线设备 | 主线设备问题 |
| 软件集成（SIE） | SIE软件集成问题 |
| 生产/工艺 | 生产或工艺问题 |
| 生产 | 生产相关问题 |
| 工艺 | 工艺相关问题 |
| 维护 | 维护相关问题 |
| IT | IT相关问题 |
| 待办项 | 待办事项 |
| 其他 | 无法归类的问题 |

### 3.2 问题区块识别
- 开始标记：`【问题汇总】`
- 结束标记：`【测试结果】` 或 `【今日计划实际是否完成】` 或 `【明日的测试计划】` 或 `【下周的测试计划】`

### 3.2 类别前缀（需移除）
| 类别 | 前缀 |
|------|------|
| 投收板机 | `投收板机：` |
| 自动化物流 | `自动化物流（海康）：` |
| 主线设备 | `主线设备：` |
| 软件集成 | `软件集成（SIE）：` |
| 生产/工艺 | `生产/工艺：` |
| 生产 | `生产：` |
| 工艺 | `工艺：` |
| 维护 | `维护：` |
| IT | `IT：` |
| 待办项 | `待办项：` |

### 3.3 序号清理
- 中文序号：`①②③④⑤` → 移除
- 数字序号：`1.` `2、` `3)` → 移除

## 4. 问题状态判断

### 4.1 状态关键词

| 状态 | 关键词 | 优先级 |
|------|--------|--------|
| **已解决** | `已解决`、`已完成`、`已修复` | 最高 |
| **排查中** | `排查`、`正在排查` | 中 |
| **待处理** | `待`、`尚未`、`未完成` | 低 |
| **无** | `无`（单独一行时） | - |

### 4.2 判断逻辑
```
if 包含 "已解决" or "已完成" or "已修复":
    → 已解决
elif 包含 "排查":
    → 排查中
elif 包含 "待" or "尚未" or "未完成":
    → 待处理
else:
    → 待处理（默认）
```

---

## 5. 线体识别

### 5.1 可识别线体
| 线体 | 识别关键词 |
|------|-----------|
| VCP1 | `VCP1`（不区分大小写） |
| VCP2 | `VCP2`（不区分大小写） |
| PLB | `PLB`（不区分大小写） |
| 通用 | 以上都不包含 |

### 5.2 多线体
- 一个问题可涉及多个线体
- 用逗号分隔：`VCP1, VCP2, PLB`

## 7. 统计口径

| 指标 | 计算方式 |
|------|----------|
| 问题总数 | 问题列表中所有条目（不含"无"） |
| 已解决 | 状态="已解决"的数量 |
| 待处理 | 状态="待处理"的数量 |
| 排查中 | 状态="排查中"的数量 |
| 未解决问题 | 待处理 + 排查中 |
| 线体问题数 | 按线体分组统计各状态数量 |

---

## 8. 关键词库

### 状态关键词
```
已解决: 已解决, 已完成, 已修复
排查中: 排查, 正在排查
待处理: 待, 尚未, 未完成
```

### 线体关键词
```
VCP1: VCP1, vcp1
VCP2: VCP2, vcp2
PLB: PLB, plb
```

### 特殊处理
- `生产暂停` → 不是问题状态，是客观描述
- `甲方经理验收` → 不是问题，是中断原因
- `设备在生产` → 不是问题，是暂停原因
